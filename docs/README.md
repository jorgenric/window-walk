## Conventions

- File names are lowercase and hyphenated, such as `owner-interviews-alberta.md`.
- Put a date and author near the top of each document, and say "as of" for anything that can go stale.
- Research notes record where each finding came from: a link, or who said it and when.
- Open questions and next steps go in the project [to-do list](../TODO.md), not in individual docs. When one is settled, add a decision record and tick off the item.
