# Decisions

One short Markdown file per decision, numbered in the order they're made: `0001-first-corridor.md`, `0002-host-organization.md`, and so on. Many will settle items on the [to-do list](../../TODO.md). Name the item ID in the record, such as "Settles C-01," and link the record from the item when you tick it off.

Records are never deleted. If a decision changes, write a new record and mark the old one as superseded.

## Template

```markdown
# 0000: Title

- Status: proposed | accepted | superseded by 00XX
- Date: YYYY-MM-DD
- Decided by:
- Settles: C-00

## Context
What question needed answering, and why now.

## Decision
What was decided.

## Consequences
What this makes easier or harder, and what follows from it.
```
